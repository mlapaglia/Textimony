# Textimony
What your SMS messages reveal about you

1. Export your Android Google Messages chats using [SMS Backup & Restore](https://play.google.com/store/apps/details?id=com.riteshsahu.SMSBackupRestore).
2. Navigate to https://mlapaglia.github.io/Textimony/
4. Import the xml backup(s)
5. Look at fancy graphs!

All processing occurs in the browser, your data is never uploaded anywhere!
