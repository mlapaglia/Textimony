SMS & MMS

Android phones

  1. Install SMS Backup & Restore on your phone.
  2. Back up Messages, and Calls too if you want call stats.
  3. Copy the backup files to this computer, or save them to a cloud drive and download them.

Choose sms-….xml and, optionally, calls-….xml

💬

Google Chat

Google Takeout

  1. Open Google Takeout and click Deselect all.
  2. Tick Google Chat, then Next step → Export once, .zip → Create export.
  3. When Google emails you, download every part of the export.

Choose takeout-….zip, all parts together if it was split

Dates are only understood when your Google account language is English.

Open Google Takeout ↗
🟢

WhatsApp

Android or iPhone

  1. Open a chat, then ⋮ (Android) or the contact or group name (iPhone).
  2. Tap Export chat, with or without media, and send it to yourself.
  3. Repeat for every chat you want to include.

Choose WhatsApp Chat with ….txt or WhatsApp Chat - ….zip

Exports don't say which sender is you. Yapalytics guesses, and you can correct it under You on WhatsApp.

iMessage

On a Mac

  1. Install the free imessage-exporter with Homebrew: brew install imessage-exporter
  2. Run it. Add -c clone to copy attachments too. imessage-exporter -f txt
  3. It writes one .txt per conversation to ~/imessage_export.

Choose the .txt files, or a .zip of the folder

Terminal needs Full Disk Access (System Settings → Privacy & Security). To read an iPhone backup instead, add -p and the backup folder.

GitHub ↗ Homebrew ↗
✈️

Telegram

Telegram Desktop

  1. Install Telegram Desktop on a computer and sign in.
  2. Open Settings → Advanced → Export Telegram data. For one chat, use its ⋮ menu → Export chat history.
  3. Set Format to Machine-readable JSON and export.

Choose result.json, or a .zip of the export folder to see photos

The HTML format can't be read. The lighter Telegram for macOS app has no export, so use Telegram Desktop.

Tips

  • Choose exports from several apps at once. Each conversation is marked with its app (💬 🟢 🔵 ✈️), and the source switch compares them.
  • Use + Add files on the dashboard to bring in more later. Overlapping exports are merged, not counted twice.
  • Not ready to export? The demo shows every chart with made-up conversations.
